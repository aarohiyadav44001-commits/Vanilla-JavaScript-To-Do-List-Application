📝 To-Do List Application
📖 Overview

A modern and interactive To-Do List application built using HTML, CSS, and Vanilla JavaScript. This project helps users organize their daily tasks efficiently through a clean and responsive interface while demonstrating core JavaScript concepts such as DOM manipulation, event handling, state management, and browser storage.

✨ Features
Create, edit, and delete tasks
Mark tasks as completed or active
Filter tasks by All, Active, and Completed status
Dynamic user interface updates without page reloads
Data persistence using Local Storage
Responsive and user-friendly design
Efficient event handling through event delegation
🛠 Technologies Used
HTML5
CSS3
JavaScript (ES6)
Local Storage API
🎯 Learning Objectives

This project showcases practical implementation of:

DOM Manipulation
Event Handling
State Management
CRUD Operations
Local Storage Integration
Dynamic Rendering
